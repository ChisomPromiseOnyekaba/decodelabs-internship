# DecodeLabs Data Analytics Internship — Batch 2026

Data analytics projects completed during my Data Analytics 
Internship at DecodeLabs (4-week Industrial Training Kit).

## 📊 Dataset
1,200 e-commerce order records (Jan 2023 – Jun 2025) covering 
products, customers, payments, referrals and order statuses.

## 🗂️ Projects

### Project 1 — Data Cleaning & Preparation
Identified and resolved missing values, standardized formats, 
and verified zero duplicate IDs. Documented all changes in a 
PDF Change Log.
**Tools:** Microsoft Excel

### Project 2 — Exploratory Data Analysis (EDA)
Calculated descriptive statistics (mean, median, IQR), 
identified outliers using the IQR method, and built 
PivotTables/charts to uncover revenue trends, top products 
and operational issues.
**Tools:** Microsoft Excel

### Project 3 — SQL Data Analysis
Wrote 10 SQL queries using SELECT, WHERE, GROUP BY, ORDER BY, 
HAVING and aggregate functions (COUNT, SUM, AVG) to extract 
business insights from a 1,200-row orders table.
**Tools:** PostgreSQL, pgAdmin

### Project 4 — Data Visualization
Built an interactive dashboard with 8 visualizations (bar, 
line, pie, donut, column charts), 4 KPI cards, and 2 slicers 
to communicate key business insights.
**Tools:** Power BI

## 🔍 Key Insights Across All Projects
- Total Revenue: $1,264,761.96 across 1,200 orders
- 41.4% of orders are Cancelled or Returned — critical issue
- Instagram drives the most referral revenue ($275K)
- Revenue peaks in June, drops sharply by September
- Revenue declined 13% from 2023 to 2024
